[1. 작업 개요 및 배포 현황]
- 시스템 목적: Deepwoken 빌드 영상 및 웹 문서(나무위키, Fandom, Google Docs) 자동 분석 ➔ 100% 한국어 고밀도 카드 출력 ➔ deepwoken.co 주입용 JSON 생성 ➔ GitHub 자동 백업 및 24/7 디스코드 서비스.
- 클라우드 배포: Render.com 24/7 Background Worker (`Dockerfile`, `render.yaml`, `Procfile` 탑재 완료).
- API 키 풀: 5개 Gemini API Key Failover (`AQ.Ab8...`) 로테이션 매니저 연동.

[2. 모듈 및 데이터 흐름 맵]
1) 영상 파이프라인: pipeline/orchestrator.py
   - agents/collector.py: yt-dlp Android/iOS 클라이언트 우회 다운로드
   - agents/analyzer.py: Gemini Files API 비디오 업로드 및 멀티모달 JSON 추출
   - agents/structurer.py: 표준 JSON Schema 검증 및 data/analysis/ 저장
2) 웹/지식 파이프라인: pipeline/web_orchestrator.py
   - agents/web_scraper.py: HTML 파싱 + 403 차단 시 DuckDuckGo Search Grounding 대체
   - agents/subagents/: 5개 서브에이전트 협업 분석 (BuildParser, ContextParser, CrossValidator)
3) 지식베이스 및 어드바이저:
   - agents/knowledge_builder.py: ChromaDB 벡터 임베딩 인덱싱
   - chatbot/build_advisor.py: ChromaDB RAG + DuckDuckGo 실시간 검색 하이브리드 어드바이저
4) 디스코드 봇: discord_bot.py
   - Single-Instance Mutex (소켓 락)
   - 1-by-1 순차 대기열 락 (asyncio.Lock)
   - create_rich_build_embed (한국어 브리핑, Pre/Post 스탯, 장비/인챈트, 만트라 밑 보스사냥법, 장단점)

[3. 주요 트러블슈팅 및 해결 내역]
1) YouTube Bot Detection ('Sign in to confirm you're not a bot'):
   - 원인: 해외 클라우드 IP에서의 웹 클라이언트 요청 차단
   - 해결: extract_metadata_only 및 download에 'player_client': ['android', 'ios', 'web_embedded', 'web'] 전면 적용
2) 웹 스크래핑 403 Forbidden:
   - 원인: Cloudflare 보호 사이트(나무위키 등) 접근 제한
   - 해결: 403 발생 시 DuckDuckGo Search Grounding으로 자동 전환하여 문서 요약 및 공략 생성
3) 3중 중복 응답 현상:
   - 원인: 구버전 백그라운드 프로세스 복수 실행
   - 해결: 단일 인스턴스 소켓 락(포트 49281) 적용으로 중복 실행 원천 차단
4) 1-by-1 순차 처리:
   - 다중 링크 유입 시 API 쿼터 충돌 방지를 위해 asyncio.Lock 대기열 시스템 적용
