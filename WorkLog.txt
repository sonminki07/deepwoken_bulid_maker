1. 프로젝트 개요
   - 사용자가 여러 개의 링크(유튜브, 웹, 구글 닥스)를 일괄 예약해 두고 순차 분석할 수 있는 대기열(Queue) 시스템 구축.
   - 무료 API 키의 일일 쿼터 초과(429/ResourceExhausted) 시 준비된 다음 API 키로 자동 전환(Failover)하는 스마트 키 매니저 구현.
   - 컴퓨터 전원/상태에 따른 백그라운드 자동 실행 가이드 및 클라우드 배포 솔루션 지원.

2. 추가 구현 및 개선된 컴포넌트 목록
   - [Queue Reservation Manager]
     * agents/queue_manager.py: `data/queue.json` 기반 링크 일괄 등록 및 순차 처리 백그라운드 워커.
     * gui_app.py 내 `📋 일괄 예약/대기열 (Queue)` 팝업 지원: 여러 개의 링크를 줄바꿈으로 한 번에 붙여넣어 일괄 처리 가능.
     * main.py: `python main.py queue` 명령어 추가.
   - [Multi-API Key Failover Engine]
     * agents/key_manager.py: `.env` 파일에 쉼표로 나열된 여러 개의 Gemini API 키(`GEMINI_API_KEYS=키1,키2,키3`)를 자동 감지.
     * 429 ResourceExhausted 에러 발생 시 즉각 다음 키로 순환(Rotate)하여 분석 중단 방지.
     * agents/analyzer.py, agents/subagents/build_parser.py, agents/subagents/context_parser.py 전면 연동.

   - GUI 내 대기열 팝업 창 연동 테스트 완료
